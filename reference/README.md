# Referenz

`mausritter-srd-2.3.1.md` ist das offizielle **Mausritter System Reference Document**
(Version 2.3.1, Stand 2026-02-21), heruntergeladen von <https://mausritter.com/srd/>
(dort: „Download as Markdown file").

Es steht unter der **Creative Commons Attribution 4.0 International (CC BY 4.0)** Lizenz.
Mausritter © Isaac Williams & Losing Games.

Diese Datei ist die **verbindliche Quelle** fuer alle Regel- und Datenfragen im Projekt.
Die Inhalte in `src/data/*` sind daraus abgeleitet; Wirkungstexte werden zusammengefasst,
nicht woertlich uebernommen.

## PDFs (lokal, NICHT im Repo)

Die frei von mausritter.com herunterladbaren PDFs (Regelbuch 2.3, Charakter-, Item-,
Zustands- und SL-Boegen) liegen hier nur lokal zur Referenz. Sie sind per `.gitignore`
ausgeschlossen: Regeln und Mechaniken stehen unter CC BY 4.0, das **Artwork und Layout
aber ausdruecklich nicht** — eine Weitergabe der PDFs im oeffentlichen Repo waere daher
nicht zulaessig. Fuer die Entwicklung auf das SRD-Markdown stuetzen.
